# Client - Streamlit Frontend

This directory contains the Streamlit client that provides a web interface for the SawserQ GPT system.

## Structure

```
client/
├── client_streamlit.py   # Main Streamlit application
├── client.py            # Simple HTTP client
└── requirements.txt     # Client dependencies
```

## Usage

```bash
# Install dependencies
pip install -r requirements.txt

# Start the Streamlit client
streamlit run client_streamlit.py
```

## Features

- Interactive chat interface
- Real-time health monitoring
- Document processing controls
- Context information display
